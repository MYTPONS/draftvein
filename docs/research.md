# 读者圈 / 作者圈 调研 → 功能取舍

调研时间：2026-11-24。来源为公开网页（工具横评、作者社区转帖、官方功能说明），只当需求信号，不照抄文案。

## 一、反复出现的痛点（多来源一致）

| 痛点 | 证据 |
| --- | --- |
| **人物名字前后对不上 / 人设崩** | 工具横评原文：「单次生成往往很漂亮，可一旦写成长篇，人物名字前后对不上、伏笔埋了不收、文风说变就变」。来源：[百家号横评](https://baijiahao.baidu.com/s?id=1882640006583651726) |
| **设定冲突率高** | 「AI 写小说设定冲突率超 60%…人物关系混乱，剧情前后矛盾，像两本不同的小说」。来源：[今日头条](https://www.toutiao.com/article/7657450076998779398/) |
| **五类不一致**：事实细节 / 时间线 / 人物性格 / 世界设定 / 叙述风格，且随字数线性增长 | 微软 ConStory-Bench 研究综述：[科技行者](https://www.techwalker.com/2026/0318/3181470.shtml) |
| **上下文记忆薄弱 → 中后期崩** | 「长篇连载需要工具留存上万字前文、梳理伏笔、人物关系、世界观；上下文弱的工具写到中后期人设崩塌」。来源：[今日头条](https://www.toutiao.com/article/7665984110082490907/) |
| **一眼 AI 味 → 读者弃书** | 横评里点名某些模型「中文输出自带翻译腔，读者一眼看出来是 AI 写的，易弃书掉收」。来源：[百家号排雷](https://baijiahao.baidu.com/s?id=1880893781264107952) |

## 二、成熟工具都在做什么（功能基线）

- **作家助手（阅文官方）**：总纲/章纲分离、AI 提取章纲、**角色卡（可回溯提及章节）**、伏笔追踪、码字统计（含日历）、作品数据推送、写完直发平台。来源：[官方功能说明](https://nav.eyosc.com/sites/3606.html)、[码字统计](https://write.qq.com/ask/qfokgjd)
- **马良写作**：卷章目录 + 角色卡 + 伏笔台账 + 故事档案，主打「防写崩」。
- **灵蟹创作**：AI 责编按选题/创意/人物/节奏/文笔五维打分、列**毒点清单**、BYOK。
- **好好码字**：码字计划、日历打卡、时长/字数图表、小黑屋模式（锁字数）。来源：[好好码字](https://www.haohaomazi.com/)
- **角色卡字段惯例**：姓名/年龄/身份/外貌/性格/背景/**说话方式/口头禅**/关系/禁忌。来源：[制卡模板](https://apizzai.com/persona-template)、[OC 模板](https://litmemo.com/zh-Hans/templates/oc-template)
- **人物关系管理**（阅读器侧也有）：角色、别名、颜色、关系图。来源：[Reeden 文档](https://docs.reeden.app/characters_relations)
- **万订作者经验（龙空转帖摘要）**：开篇做减法、不要造词、信息必须有用、金手指要给出实际收获、人设是「异于常人的点」。来源：[NGA 转帖](https://bbs.nga.cn/read.php?tid=44167146)

## 三、据此补齐的东西（本轮已实现）

1. **人物卡系统**（`characters` 表 + 「人物」页）：姓名/别名/定位/身份/外貌/性格/想要/怕/**说话方式/口头禅/禁忌**/关系/状态/首次登场/提及章数/重要度。
   - 第一次规划时自动建 3 人（1 主角 + 2 配角，其中至少 1 个对立面）；之后可编辑。
   - 章节计划里的 `characters` 只允许已登记名字，未登记的会被剔除并提示。
   - 写正文时人物卡（含口头禅）直接进 prompt；审稿会查「人物卡之外的新名字 / 说话方式不符 / 已死亡人物又出现」。
   - 落库回写 `first_idx / last_idx / mentions`；正文里重复出现且未登记的人名会被抓出来提示补卡。
2. **文风样本**（书信息里可贴自己的一段文字）：进 prompt 作语感参照，治「文风说变就变」。
3. **码字统计条**：今日 / 近 7 天 / 全书 / 日均，加 14 日柱状。
4. **毒点维度**：审稿新增 `poison`（信息过载、造词、金手指无收益、无意义铺垫）与 `characters` 两个维度。
5. **写作规则**：`BASE_SYSTEM` 增加「开篇做减法 / 不造词 / 信息必须有用 / 人设写异于常人的点」——来自龙空万订作者经验摘要。

## 五、不做的

- 不做「AI 责编按选题打分荐稿」这类平台运营向功能（与作者自用无关）。
- 不做「一键生成整本」——这正是本项目要反对的东西。
